# Clase 1 - Tipos Abstractos de Datos

Proyecto organizado para GitHub con los dos TAD solicitados.

## Carpetas
- `TAD_Fraccion`: implementación, pruebas y documentación del TAD Fracción.

Para ejecutar cada ejercicio, entrar a su carpeta y ejecutar `python main.py`.
