# TAD Punto2D

**Dominio:** pares ordenados `(x, y)` de números reales.

## Operaciones
- `crear(x, y) -> Punto2D`: crea un punto con coordenadas `(x, y)`.
- `coordenadaX(p) -> Real`: devuelve `x` sin modificar el punto.
- `coordenadaY(p) -> Real`: devuelve `y` sin modificar el punto.
- `distancia(p1, p2) -> Real`: devuelve la distancia euclidiana sin modificar los puntos.
- `trasladar(p, dx, dy) -> Punto2D`: devuelve un nuevo punto `(x + dx, y + dy)` sin modificar el original.
